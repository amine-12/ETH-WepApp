# Mission

Crée un site web éducatif moderne et interactif sur les enjeux éthiques liés à l'intelligence artificielle.

Le site est réalisé dans le cadre du cours universitaire ETH610.

L'objectif n'est pas simplement de présenter du texte. Le site doit permettre à un utilisateur :

- d'apprendre les principaux enjeux éthiques de l'IA;
- de naviguer facilement entre plusieurs modules;
- de progresser à travers les contenus;
- de répondre à des questions;
- de participer à des mini-jeux;
- d'obtenir immédiatement une rétroaction pédagogique;
- de voir sa progression.

Pour cette première version, crée uniquement le frontend.

Ne configure pas encore Supabase, de base de données ou de système d'authentification.

Cependant, structure le code pour permettre d'ajouter plus tard :

- une base Supabase;
- le stockage des réponses;
- des statistiques d'utilisation;
- des sessions anonymes;
- un tableau de bord administrateur.

---

# 1. Technologies

Utiliser :

- React
- TypeScript
- Vite
- React Router
- CSS moderne ou Tailwind CSS
- Lucide React pour les icônes

Pour les animations, utiliser des animations CSS légères ou Framer Motion si cela apporte une vraie amélioration.

Éviter les dépendances inutiles.

Le projet doit fonctionner avec :

```bash
npm install
npm run dev
```

et être compilable avec :

```bash
npm run build
```

# 14. Mini-jeu — Trouvez l'hallucination

Utiliser le mini-jeu prévu dans le contenu pédagogique.

Afficher plusieurs paragraphes du module.

Une affirmation volontairement fausse doit être présente :

```text
En 2024, l'UNESCO a lancé un système appelé
« Global AI Truth Index » permettant de noter la fiabilité

```

Demander :

```text

```

```text

```

```text

```

Indice :

```text
Cherchez dans la partie sur la désinformation.
```

Lorsque l'utilisateur trouve la réponse :

afficher une animation légère et expliquer pourquoi l'affirmation semblait crédible.

Message final :

```text
Une organisation connue, une date précise et un nom crédible
ne garantissent pas qu'une information soit vraie.
```

Attribuer des caractéristiques humaines à quelque chose qui ne l'est pas.

Présenter les risques :

- croire que l'IA comprend réellement;
- lui attribuer des émotions;
- dépendance;
- confiance excessive;
- réduction du jugement critique;
- confusion entre imitation et relation réelle.

Par exemple :

```typescript
interface LearningModule {
  id: string;
  number: number;
  title: string;
  description: string;
  estimatedMinutes: number;
  icon: string;
  sections: ModuleSection[];
}
```

Cela permettra d'ajouter ou modifier les modules sans reconstruire toute l'application.

# 46. Préparer l'intégration future avec Supabase

Même si Supabase ne doit PAS être ajouté maintenant, préparer le frontend.

Les actions suivantes doivent passer par des services :

```text

saveProgress()
completeModule()
trackModuleOpen()
trackGameResult()
```

Pour l'instant, ces fonctions utilisent uniquement `localStorage`.

Plus tard, elles seront remplacées par des appels à Supabase.

Ne pas coupler les composants à `localStorage`.
